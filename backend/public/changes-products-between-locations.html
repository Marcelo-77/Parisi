How to use Changes Between Locations

What this screen does

Moves all active product balances from one location to another. The system writes DELETE entries for the source balances and INSERT (or UPDATE when merging) entries for the destination, always using the logged-in user key.

Steps

  • Type or scan the Source location code.
  • Type or scan the Destination location code.
  • Click Preview to review before and after.
  • Click Confirm move to apply the change.

Mobile

  • On phones, use the Scan buttons to read location barcodes with the camera.
  • Press F1 anytime to open this Help.
