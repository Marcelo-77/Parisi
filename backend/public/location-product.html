How to use Location Product

What this screen does

Location Product links products to warehouse bins (locations), tracks quantity in each bin, and lets you print location stock reports.

Search records

  • Use filters: Location Code, Product Code, Category, Situation, and entry date range.
  • If the selected Category has subgroups (example: BathWare), a Subcategory filter appears.
  • Click Search to load records. Results are not loaded until you search.
  • Click Clear to reset filters and the result list.
  • Click Download to export the current search results to Excel (Location Code, Product Code, Qty Current, Inserted By, Date Time Last Update).

New Record

  • Click New Record to open the line-entry panel.
  • Enter Location Code, Product Code, Situation and Qty Informed.
  • Use Add Line for more rows, then Save All Lines.
  • When Situation is Full, quantity updates warehouse stock.

Edit and Delete

  • Edit — change Location Code and/or Quantity Current. Location changes are logged as exit/entry.
  • Delete — remove a location-product record (may adjust stock).

Print

  • Click Print, search and select a location, choose font size and barcode option.
  • On mobile, Close and Print stay fixed at the bottom of the dialog.
Tips
  • Location and Product codes are matched exactly (case-insensitive).
  • Search shows active records, including those with quantity current equal to zero.
  • If a location/product/situation already exists with zero quantity, saving a new record restocks it instead of creating a duplicate.
  • Press F1 anytime to open this Help.
