Classic format (how location is created today)

Read-only reference

Today New Location builds codes from Street + Building + Level + Side/Sublevel (and optional Behind / A21X). Only the composed code is saved.

Format

{street}{building}-{level}{side|sublevel}[B]

  • Street — one letter A–Z
  • Building — number (≥ 0)
  • Level — number (≥ 0)
  • Side — R / L / M
  • Sublevel — number (Level 0 or A21X)
  • Behind — optional B (Street A or H)
  • A21X — A21X1-00, A21X2-00…
