How News works

When you save a news item here, the system can show it automatically to users after they log in. Below is how each part of the form affects delivery and display.

Description

This is the main message shown in the login popup. Write clear, complete information for the target audience.

Validity period

A news item is active only when the current date is between the start date and end date (inclusive). Outside that range, it is not shown to users and does not appear in unread announcements.

Display sectors

  • All sectors — every logged-in user can receive this news (except users who already marked it as read).
  • Selected sectors — only users whose Warehouse Sector matches one of the selected sectors receive it. The sector is configured in Users → New User / Edit User.
  • Users without a sector only receive news marked as All sectors.
  • The Root account sees all active unread news, regardless of sector.

Attachments

Attachments are optional. They must already exist in System Documentation. Linked files appear in the login popup with a download link so users can open or save the document.

Login popup and read confirmation

After login, on the first authenticated page in the session, the system loads unread news that are active and match the user's sector. If there are several, they are shown one at a time.

The user must tick "I have read this news and do not want to see it again" and click Continue. That records the read status; the same news will not be shown again to that user.

Managing existing news

Use Search news to find, edit, or delete announcements that were already created.
