How News works

When you save a news item here, the system can show it automatically to users after they log in. Below is how each part of the form affects delivery and display.

Description

This is the main message shown in the login popup. Write clear, complete information for the target audience.

Validity period

A news item is active only when the current date is between the start date and end date (inclusive).

Display sectors

  • All sectors — every logged-in user can receive this news.
  • Selected sectors — only users with a matching Warehouse Sector.
  • Users without a sector only receive All sectors news.

Attachments

Optional files from System Documentation with download links in the popup.

Read confirmation

Users must confirm they read the news; it will not be shown again to that user.
