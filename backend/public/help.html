Help Center

Overview

Double-Y Warehouse System manages inventory, locations, movements, and the picking workflow. Use the header menus to navigate between modules.

System Modules

  • Users — register and search system users.
  • Customer — create and search customers linked to movements.
  • Product — add products and search warehouse inventory.
  • Location — manage warehouse locations and product placement.
  • Movement — create, search, and track movement status.
  • Picking — handle order picking, separation, double checking, and labels.

Picking Workflow

  1. Picking List — view items ready for picking (Phase 2, Type 1).
  2. Order Sent for Picking — filter and locate orders by movement or product.
  3. Separation and Picking — separate and confirm picked quantities.
  4. Double Checking — verify picked items before dispatch.
  5. Last check and Label — final validation and label printing.
