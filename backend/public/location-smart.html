How to use Location Smart

What this screen does

Location Smart creates a full copy of an existing location set (Street + Building) into a new set, keeping every Level and Side/Sublevel combination, plus Status, Access Type and Section.

Steps

  • Choose the Source set (example: A1).
  • Type the New set (example: A2).
  • Click Generate lines to preview all new locations.
  • Adjust Status per line if needed.
  • Click Save All to create every new location that does not already exist.

Duplicates

  • If the new code already exists (exact), the line is skipped.
  • If an old-format equivalent exists (example: C61R ≡ C6-1R), it is also skipped.
  • Skipped duplicates appear in the Existing as column and in the list under the table.
Example
  • Source A1 has A1-00, A1-1R, A1-1L.
  • New set A2 generates A2-00, A2-1R, A2-1L.
  • If A21R already exists, A2-1R is listed as duplicate and not created.
