How to search Locations

What this screen does

Use Search Location to find warehouse bins, edit their details, print or download bin labels, and export results to Excel.

How to search

  • Fill one or more filters, then click Search.
  • You can search by Street, Building, Level, Side/Sublevel, full Location code, Status, Section or Access Type.
  • The Location field can be typed directly (example: B15-1L) or built from Street/Building/Level.
  • Click Clear Filters to reset all search fields.

Level 0 filters

  • When Level is 0, choose Level 0 type: Side or Sublevel.
  • When Level is greater than 0, use Side (R / L / M).

Results and actions

  • Edit — change Status, Access Type, Section or rebuild the Location code.
  • Print — print a bin label (choose label size first).
  • Download — export the current search results to Excel.
Examples
  • Street B only → all locations starting with B
  • Location B1-00 → exact (or matching) bin code
  • Status Active + Section BathWare → active BathWare bins
