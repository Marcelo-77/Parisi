Tips

  • Choose SMS or Email as the default send method for Location Product requests.
  • If Driver can reassign is Yes, any forklift driver can pass Waiting requests to another driver.
  • If No, Waiting requests can only be taken by the logged-in driver.
  • If Control time Waiting is Yes, set minutes and who gets an email after that wait.
  • If Mark all day requests Inactive is Yes, after the cutoff time all requests of the day become Inactive and Search shows Active only.
  • If Notify requester when Completed is Yes, the requester is messaged when status becomes Completed (default is No).
  • Only active Parisi users can be assigned or selected for timeout messages.
  • Assigned drivers must have phone and/or email for SMS or Email requests.
  • Location Product forklift requests use this Assigned list.
