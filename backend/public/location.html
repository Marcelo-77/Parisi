How to create a Location

What is Location?

The Location code is generated automatically from Street, Building and Level. You cannot type it manually. It updates at the top of the form as you fill the fields.

Required address fields

  • Street — one letter (A–Z), for example A or B.
  • Building — a number, for example 7 or 15.
  • Level — shelf/rack level number. Use 0 for ground level, or 1, 2, etc. for upper levels.

When Level is 0

Choose a Level 0 type:

  • Side — then select R (Right), L (Left) or M (Middle).
  • Sublevel — then enter a sublevel number (for example 0).
  • For Street A or H, after typing Sublevel you can choose B - Behind or leave it empty (None).

When Level is greater than 0

Select the Side (R / L / M). Level 0 type and Sublevel are not used.

Special case: Street A + Building 21

For A21, the X field is optional.

  • Leave X empty → normal location, for example A21-00 or A21-0R.
  • Fill X (1, 2, 3, …) + Sublevel → A21X1-00, A21X2-01, etc.

Only when X is filled: Level is 0, Access Type is Shelf by Hand, Section is Other, and Behind is not available.

Classification

  • Section — warehouse area (Tapware, BathWare, Furniture, etc.).
  • Access Type — how the bin is reached (by Hand, Wave or Fork).
  • Status — Active or Inactive.
Examples
  • Street B, Building 1, Level 0, Sublevel 0 → B1-00
  • Street A, Building 7, Level 0, Sublevel 0 → A7-00
  • Street A, Building 7, Level 0, Sublevel 0, Behind B → A7-00B
  • Street A, Building 21, Level 0, Sublevel 0 (no X) → A21-00
  • Street A, Building 21, X 1, Sublevel 0 → A21X1-00
  • Street A, Building 21, X 1, Sublevel 1 → A21X1-01
  • Street A, Building 21, X 2, Sublevel 0 → A21X2-00
  • Street B, Building 15, Level 1, Side L → B15-1L
  • Street A, Building 7, Level 2, Side R → A7-2R
